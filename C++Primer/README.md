# C++ Primer 学习笔记

本目录按《C++ Primer》的主题保存可独立编译的小示例。代码以“先运行、再对照注释理解语言规则”为目标，而非可复用的生产组件。

## 目录导航

| 目录 | 当前示例 | 建议关注点 |
| --- | --- | --- |
| `Template/` | `com.cpp` | 函数模板、模板实参推导，以及模板对运算符的要求 |
| `OOP/` | `quote.*` | 动态绑定、继承层次与报价策略（该组文件已单独维护） |
| `smart_point/` | `strblob.*` | `shared_ptr` / `weak_ptr` 与容器共享所有权（该组文件已单独维护） |

## 推荐学习路径

1. **模板基础**：先阅读 `Template/com.cpp`，确认 `typename T` 如何令同一份比较逻辑适用于多种可比较类型。
2. **对象导向**：再进入 `OOP/`，观察基类接口、虚函数和派生类重写如何共同实现运行时多态。
3. **资源管理**：最后学习 `smart_point/`，把“对象生命周期”与标准智能指针的所有权语义联系起来。

## 编译与运行

所有示例使用 C++11 及以上标准即可。以模板示例为例：

```bash
c++ -std=c++11 -Wall -Wextra -pedantic Template/com.cpp -o /tmp/primer-template
/tmp/primer-template
```

> 笔记中的示例刻意保持短小。修改模板实参类型时，请确认该类型提供示例所调用的运算符；否则错误会在模板实例化位置出现。

## 阅读记录方式

建议每个示例都记录三件事：输入/对象状态、编译器选择的函数（或模板实例）、以及输出或资源释放时机。这样可以把语法表象和实际对象模型对应起来。
