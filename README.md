# C++ 代码练习

## 仓库内容

本仓库整理 C++ 课程练习、教材跟读小示例、STL 实验，以及 Unix/网络编程相关源码。自写的学习示例以“可独立编译、顶部说明学习目标、关键位置中文注释”为约定；`apue/`、`muduo/` 等大型上游源码保留原始结构，以便与原书和上游版本对照。

- **全项目地图与模块内部结构：** [项目知识体系.md](<项目知识体系.md>)
- **按概念依赖的阅读顺序：** [学习路线.md](<学习路线.md>)
- **STL 完整主题与示例索引：** [STL/README.md](<STL/README.md>)

建议先完成 C++ 基础、面向对象和模板，再进入 C++11/14 与 STL；系统和网络编程部分放在后面。课件位于 [PPT](<PPT/>) 目录。

第二部分属于对陈硕 muduo 学习的资料与源码。
