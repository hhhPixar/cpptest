# 条款实验的编写约定

本目录的 `termNN.cpp` 与《Effective C++》第三版的 **Item NN** 一一对应。每个文件均应满足：

1. 可独立用 C++14 编译、链接、运行；
2. 在文件顶部写清条款主题、学习目标和现代 C++ 说明；
3. 至少包含一个可运行的正例，以及必要时用 `#if 0` 保留的错误反例；
4. 注释解释资源所有权、对象状态、动态类型、异常保证或模板实例化等关键过程；
5. 只以原创代码解释条款，不复制原书正文或例程。

## 文件命名

```text
term01.cpp  <=> Item 1
term02.cpp  <=> Item 2
...
term55.cpp  <=> Item 55
```

本目录只保留 `termNN.cpp` 作为每条的唯一代码入口；不保留跨条款的 `itemNN_MM-*.cpp` 分组示例，以免与逐条学习结构重复或混淆。

## 单条示例的阅读方法

1. 读顶部注释，先明确此条防止的错误；
2. 看对象、指针、引用或模板参数在运行前后的状态；
3. 编译运行，核对输出；
4. 打开 `#if 0` 中的反例，理解它为何不能作为正式代码编译；
5. 回到原书阅读完整论证和适用边界。

## 现代化边界

原书第三版发布于 C++11 前。仓库使用 `unique_ptr`、`shared_ptr`、`=delete`、`override` 等现代工具时，目的在于表达同一设计约束，而非将《Effective Modern C++》的条款混入本书。源代码中会标明这种现代等价关系。
